## Where to go
Citadel Help covers product setup and operation. Use the [StealthRDP client area](https://dash.stealthrdp.com/clientarea.php) for plans, invoices and renewals.
For a human response, [submit a support ticket](https://dash.stealthrdp.com/submitticket.php?step=2&deptid=5) or email `support@stealthrdp.com`.
If you are still setting up protection, start with [Getting started with Citadel](/citadel/docs/getting-started).
