## Analizar un ataque DDoS

Para analizar un ataque DDoS, abre la página «Insights» de un dominio: verás los gráficos y la cronología de ataques y eventos. Los eventos de inicio y fin de un ataque incluyen la duración cuando está disponible. Los motivos de desafío y bloqueo recientes explican cómo gestionó Citadel un pico de tráfico.

Usa el atajo **«Security»** para ajustar un nivel de desafío o una lista de permitidos. Compara la cronología con [Buscar logs de dominio](/es/citadel/docs/logs) para ver el contexto de cada petición y con [Análisis de tráfico](/es/citadel/docs/analytics) para ver las tendencias de todos tus dominios.
