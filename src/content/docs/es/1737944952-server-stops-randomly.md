Si Windows Server se apaga solo, un periodo de evaluación caducado puede ser la causa.

Si usas Windows Server Evaluation, se trata de software de evaluación, no de una instalación de Windows con licencia permanente. Las ediciones de evaluación suelen tener una validez de **180 días**. Una vez caducado el periodo de evaluación, puedes usar tus propias licencias de Microsoft que cumplan los requisitos, siempre que lo permitan las condiciones de licencia aplicables de Microsoft. Eres responsable de comprobar si tu licencia es válida para el despliegue alojado previsto. StealthRDP solo proporciona la infraestructura. La licencia de Microsoft Windows no está incluida y StealthRDP no la suministra. StealthRDP no proporciona licencias SPLA, licencias RDS, claves de activación ni servicios de licencias, aunque se soliciten.

Sigue este tutorial: [Windows Server: rearmar la evaluación](/es/docs/how-to-re-activate-and-extend-your-180-day-windows-trial)

Consulta también [Licencias de Windows](/es/docs/windows-licensing).

:::info
La fecha y hora de caducidad del periodo de evaluación actual de Windows Server aparece en el área de notificación (notification area) del servidor.
:::
