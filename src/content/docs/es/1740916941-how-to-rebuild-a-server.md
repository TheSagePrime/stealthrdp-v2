_(Opcional.)_

### 6. Selecciona el sistema operativo que prefieras de la lista

## Selección del sistema operativo y conexión

- Si **seleccionas Windows** como sistema operativo, se instalará con **RDP** y podrás conectarte con **Conexión a Escritorio remoto** (Remote Desktop Connection).
- Para **el resto de sistemas operativos**, conéctate con un **cliente SSH**.

## Proceso de reinstalación y tiempo de espera

- Espera **de 3 a 5 minutos** a que termine la instalación.
- **No reinicies ni vuelvas a reinstalar** hasta que el proceso termine.
- Cuando termine, recibirás un correo electrónico de aviso (el asunto llega en inglés):
  - **"Your Windows Server is Nearly Ready!"** _(para Windows)_
  - **"Your Server is Nearly Ready!"** _(para distribuciones Linux)_
