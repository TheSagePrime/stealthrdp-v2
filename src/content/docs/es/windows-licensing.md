StealthRDP no proporciona licencias de Microsoft Windows, licencias SPLA, licencias RDS, claves de activación ni servicios de licenciamiento para tu VPS, aunque se soliciten.

## Qué significa esto

1. StealthRDP te proporciona el servidor, pero no la licencia de Microsoft.
2. La licencia de Microsoft Windows no está incluida y StealthRDP no la suministra.
3. Cuando se usa Windows Server Evaluation, se trata de software de evaluación. No es una instalación de Windows con licencia permanente.
4. El software de evaluación está pensado para evaluar y probar. No tiene licencia para uso continuado o en producción sin la licencia de Microsoft adecuada.
5. Los clientes que usen Windows son responsables de obtener y mantener las licencias de Microsoft que requiera su uso previsto.
6. StealthRDP no obtiene, suministra ni determina el licenciamiento de Microsoft de un cliente.

## Software de evaluación

Windows Server Evaluation puede proporcionarse para evaluación y pruebas, cuando esté disponible. Debe tratarse como una versión de evaluación, no como una instalación de Windows con licencia permanente. Volver a activar o ampliar el periodo de evaluación no convierte el software de evaluación en una edición con licencia para producción. Consulta [Cómo ampliar el periodo de evaluación de 180 días de Windows Server](/es/docs/how-to-re-activate-and-extend-your-180-day-windows-trial).

## Licencias de Microsoft propias del cliente

Los clientes pueden usar sus propias licencias de Microsoft aptas cuando lo permitan los términos de licencia aplicables de Microsoft. Los clientes son responsables de determinar si su licencia es válida para su despliegue previsto en un entorno alojado. La elegibilidad puede depender del acuerdo de licencia del cliente, del tipo de licencia, del estado de Software Assurance o de la suscripción, y del entorno de despliegue. StealthRDP no determina esa elegibilidad y no garantiza que una licencia concreta vaya a funcionar.
