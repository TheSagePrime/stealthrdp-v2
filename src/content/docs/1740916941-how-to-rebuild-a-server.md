How to Rebuild a Server
=======================

Last updated on Mar 13, 2025

Follow these steps to **rebuild your StealthRDP server** efficiently:

1.  **Access your Client Area** _(Skip this step if you're already in the Control Panel)._
    
2.  **Open your Server's Dashboard.**
    
3.  **Click on "Rebuild".**
    
4.  **Set a Name** _(You can enter your preferred name or generate a random one)._
    
5.  **Fill in Hostname / Timezone** _(Optional)._
    
6.  **Select Any Listed OS of Your Preference.**
    

## **OS Selection & Connection**

*   If you **select Windows OS**, it will be installed as **RDP**, and you can connect via **Remote Desktop Client**.
    
*   For **all other OS options** except Windows, connect using an **SSH client**.
    

## **Installation Process & Wait Time**

*   Wait **3-5 minutes** for the installation to complete.
    
*   **Do not restart or rebuild** until the process finishes.
    
*   Once done, you will receive an email notification:
    
    *   **"Your Windows Server is Nearly Ready!"** _(For Windows OS)_
        
    *   **"Your Server is Nearly Ready!"** _(For other Linux-based distros)_
