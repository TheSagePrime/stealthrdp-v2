Wenn Windows Server Evaluation verwendet wird, kann eine abgelaufene Testphase dazu führen, dass der Server herunterfährt.

Wenn Sie Windows Server Evaluation verwenden, handelt es sich um Evaluierungssoftware und nicht um eine dauerhaft lizenzierte Windows-Installation. Evaluierungsversionen sind in der Regel **180 Tage** gültig. Nach Ablauf des Evaluierungszeitraums dürfen Sie Ihre eigenen berechtigten Microsoft-Lizenzen verwenden, soweit die anwendbaren Lizenzbedingungen von Microsoft dies erlauben. Sie sind dafür verantwortlich zu prüfen, ob Ihre Lizenz für Ihren vorgesehenen gehosteten Einsatz gültig ist. StealthRDP stellt nur die Infrastruktur bereit. Microsoft-Windows-Lizenzen sind nicht enthalten und werden nicht von StealthRDP bereitgestellt. StealthRDP stellt keine SPLA-Lizenzen, RDS-Lizenzen, Aktivierungsschlüssel oder Lizenzdienste bereit, auch wenn Sie danach fragen.

Bitte folgen Sie dieser Anleitung: [Windows Server Rearm: Evaluation verlängern](/de/docs/how-to-re-activate-and-extend-your-180-day-windows-trial)

Siehe auch [Windows-Lizenzen](/de/docs/windows-licensing).

:::info
Das Ablaufdatum des aktuellen Windows-Server-Evaluierungszeitraums wird im Infobereich der Taskleiste (notification area) des Servers angezeigt.
:::
