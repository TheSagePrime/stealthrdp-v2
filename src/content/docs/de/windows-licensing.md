StealthRDP stellt keine Microsoft-Windows-Lizenzen, SPLA-Lizenzen, RDS-Lizenzen, Aktivierungsschlüssel oder Lizenzierungsdienste bereit, auch nicht auf Anfrage.

## Was das bedeutet

1. StealthRDP stellt den Server bereit. StealthRDP stellt die Microsoft-Lizenz nicht bereit.
2. Die Microsoft-Windows-Lizenz ist nicht enthalten und wird nicht von StealthRDP geliefert.
3. Wenn Windows Server Evaluation (Evaluierungsversion) genutzt wird, handelt es sich um Evaluierungssoftware. Sie ist keine dauerhaft lizenzierte Windows-Installation.
4. Evaluierungssoftware ist für Bewertung und Tests gedacht. Ohne passende Microsoft-Lizenzierung ist sie nicht für den dauerhaften oder produktiven Einsatz lizenziert.
5. Kunden, die Windows nutzen, sind dafür verantwortlich, die für ihren vorgesehenen Einsatz erforderlichen Microsoft-Lizenzen zu beschaffen und zu pflegen.
6. StealthRDP beschafft, liefert oder bestimmt die Microsoft-Lizenzierung eines Kunden nicht.

## Evaluierungssoftware

Windows Server Evaluation kann zur Bewertung und zum Testen bereitgestellt werden, wo sie derzeit verfügbar ist. Behandeln Sie sie als Evaluierungssoftware und nicht als dauerhaft lizenzierte Windows-Installation. Das erneute Aktivieren oder Verlängern des Evaluierungszeitraums macht die Evaluierungssoftware nicht zu einer lizenzierten Produktivedition. Siehe [So verlängern Sie den 180-Tage-Evaluierungszeitraum von Windows Server](/de/docs/how-to-re-activate-and-extend-your-180-day-windows-trial).

## Eigene Microsoft-Lizenzen des Kunden

Kunden dürfen ihre eigenen geeigneten Microsoft-Lizenzen verwenden, soweit die anwendbaren Lizenzbedingungen von Microsoft dies erlauben. Kunden müssen selbst prüfen, ob ihre Lizenz für den vorgesehenen gehosteten Einsatz gilt. Die Eignung kann vom Lizenzvertrag des Kunden, vom Lizenztyp, vom Status von Software Assurance oder Abonnement und von der Bereitstellungsumgebung abhängen. StealthRDP prüft diese Eignung nicht und garantiert nicht, dass eine bestimmte Lizenz funktioniert.
