Diese Anleitung zeigt Ihnen, wie Sie Ihr VPS-Passwort zurücksetzen: das Root- bzw. Administrator-Passwort Ihres Servers sowie das Passwort für Ihren Kundenbereich.

## VPS-Passwort zurücksetzen

Folgen Sie diesen Schritten, um Ihr **Server-Passwort** zurückzusetzen:

### 1. Rufen Sie Ihren „Client Area“ auf

_(Überspringen Sie diesen Schritt, wenn Sie bereits im „Control Panel“ sind.)_

### 2. Öffnen Sie das Dashboard Ihres Servers

### 3. Wählen Sie Ihren Server aus und klicken Sie auf „Manage“

### 4. Öffnen Sie das Menü „Options“

Öffnen Sie das Menü **„Options“** und scrollen Sie nach unten, bis Sie den Abschnitt **„Root/Administrator Password“** finden.

### 5. Klicken Sie auf „Reset Password“

### Anweisungen je Betriebssystem

- **Für Linux und Ubuntu-basierte Distributionen:** Wählen Sie **„Root User“**.
- **Für Windows-basierte Betriebssysteme:** Wählen Sie **„Administrator“**.

Nach dem Zurücksetzen erhalten Sie das **neue Passwort per E-Mail.**

## Kundenbereich-Passwort ändern oder zurücksetzen

### So ändern Sie Ihr Passwort

### 1. Rufen Sie die [Seite „Change Password“](https://dash.stealthrdp.com/index.php?rp=/password/reset) auf

### 2. Geben Sie Ihr bisheriges Passwort und Ihr neues Passwort ein

### 3. Klicken Sie auf „Save Changes“, um Ihre Zugangsdaten zu aktualisieren

### So setzen Sie Ihr Passwort zurück

### 1. Melden Sie sich aus dem „Client Area“ ab

### 2. Rufen Sie die [Seite „Password Reset“](https://dash.stealthrdp.com/index.php?rp=/password/reset) auf

### 3. Geben Sie Ihre E-Mail-Adresse ein

### 4. Klicken Sie auf „Submit“. Anschließend wird ein Link zum Zurücksetzen des Passworts an Ihre E-Mail-Adresse gesendet

Prüfen Sie Ihr E-Mail-Postfach und folgen Sie den Anweisungen, um Ihr Passwort zurückzusetzen.
